# 개인정보와 데이터 흐름

이 위젯은 현재 Windows 사용자 계정의 기존 Codex CLI·Claude Code 로그인 상태를 이용해 주간 한도를 읽습니다. 별도의 회원 가입 화면이나 계정 연동 서버는 없습니다.

| 데이터 | 사용·저장 방식 |
| --- | --- |
| Codex 로그인 | 로컬 Codex app-server에 읽기 전용 한도 요청을 합니다. 위젯이 토큰 파일을 읽거나 저장하지 않습니다. |
| Claude 로그인 | Claude Code의 로컬 OAuth 접근 토큰을 읽어 Anthropic 사용량 주소로 요청합니다. 접근 토큰은 요청 중 메모리에서 사용하며 위젯의 파일·저장소·설치 파일에 복사하지 않습니다. |
| 계정 표시 | 설치된 PC의 `codex-info.ini`, `claude-info.ini`에 계정 ID가 기록될 수 있습니다. 오른쪽 클릭 메뉴에 표시됩니다. |
| 조회 결과 | 설치된 PC의 `quota.json`, `claude-quota.json`, 표시용 텍스트 파일에 마지막 조회 결과와 시각을 기록합니다. 일시적 실패 때 30분 이내 같은 계정의 이전 정상값을 구분해 보여주기 위해 그 값과 시각도 로컬에 남깁니다. |
| 설치 로그 | `%TEMP%\CodexClaudeQuotaTray-Setup.log`에 설치 오류와 설치 경로가 기록될 수 있습니다. |

외부 통신은 각 서비스의 한도 조회, 왼쪽 클릭 시 웹 채팅 열기, Windhawk의 작업 표시줄 기호 검색에 사용될 수 있습니다. Claude 사용량 주소는 공개 문서화된 안정 API가 아니어서 동작이 바뀔 수 있습니다.

**표시 설정에서 숨긴 서비스의 조회기는 실행하지 않습니다.** 설정을 저장하면 기존 조회기를 다시 시작하면서 선택된 서비스만 실행합니다. 이전에 기록된 로컬 조회 파일은 자동 삭제하지 않습니다.

저장소와 릴리스 설치 파일에는 개인 로그인·계정·한도 캐시를 넣지 않습니다. 위젯을 중지하려면 [사용 안내](START_HERE.md)의 명령을 사용하세요. 로컬 기록까지 지우려면 중지 후 설치 폴더를 삭제합니다.

버그 신고 시 계정 ID, 이메일, 토큰, 로그인 파일, 조회 JSON 전체 또는 개인 경로가 들어 있는 로그를 그대로 공유하지 마세요.
