# 계정은 어떻게 연결되나요?

이 위젯에는 별도의 계정 연결 화면이 없습니다. **설치한 Windows 사용자 계정에서 이미 로그인한 Codex CLI와 Claude Code**의 로그인 상태를 사용합니다. 두 계정은 서로 독립적이며, 표시 설정에서 선택한 서비스의 조회기만 실행합니다.

| 서비스 | 한도를 읽는 방식 | 필요한 로그인 |
| --- | --- | --- |
| Codex | 로컬 Codex CLI의 `app-server`에 `account/read`와 `account/rateLimits/read`를 요청합니다. 위젯이 Codex 토큰 파일을 직접 읽지 않습니다. | [Codex CLI](https://learn.chatgpt.com/docs/codex/cli)를 실행해 주간 한도가 있는 ChatGPT 계정에 로그인 |
| Claude Code | 로컬 Claude Code OAuth 접근 토큰을 읽고 Anthropic의 사용량 주소에 요청합니다. 토큰 갱신이 필요하면 설치된 Claude Code의 `auth status`를 실행합니다. | [Claude Code](https://code.claude.com/docs/en/setup)를 실행해 `claude.ai` 구독 계정에 로그인 |

Claude 사용량 주소는 공개 문서화된 안정 API가 아닙니다. 서비스 구조가 바뀌면 이 위젯의 Claude 조회도 영향을 받을 수 있습니다. 현재 버전은 Windows 사용자 npm 전역 설치 경로를 사용하므로 CLI를 다른 방식으로 설치하거나 WSL 안에만 로그인한 경우 인식하지 못할 수 있습니다.

## 처음 연결하기

PowerShell에서 **사용할 서비스만** 실행하고 로그인 화면을 완료합니다.

```powershell
codex
```

```powershell
claude
```

그다음 위젯을 설치하거나 Windows에서 다시 로그인하세요. 위젯 오른쪽 클릭 메뉴의 **계정 ID**와 **상태**를 확인하면 어떤 계정의 한도를 읽고 있는지 알 수 있습니다. 계정을 바꾼 뒤에는 해당 CLI에서 먼저 새 계정으로 로그인하세요. 위젯이 로그인 창이나 비밀번호 입력을 대신 처리하지 않습니다.

## `--%`와 `~83%`는 무엇인가요?

- `--%`: 아직 성공한 조회가 없거나, 로그인 정보·7일 한도·서비스 응답을 읽을 수 없습니다. 오른쪽 클릭의 **상태**와 [문제 해결](TROUBLESHOOTING.md)을 확인하세요.
- `~83%`: 요청 제한(`429`)이나 일시적 네트워크 오류가 났지만 **같은 계정의 30분 이내 마지막 정상 조회값** 83%가 있습니다. `~`는 이전 값임을 뜻합니다. 오른쪽 클릭에서 마지막 정상 조회 시각을 볼 수 있습니다.
- `83%`: 최근 조회에 성공한 주간 잔여 비율입니다.

요청 제한은 계정 연결 해제를 뜻하지 않습니다. 위젯은 약 2분 간격으로 다시 조회합니다. 표시 설정에서 다른 서비스를 끄거나 켤 때 이미 실행 중인 조회기는 다시 시작하지 않아 추가 요청을 줄입니다.

## 로그인 정보는 어디에 남나요?

Codex 로그인은 Codex CLI가 관리합니다. Claude OAuth 접근 토큰은 Claude Code의 로컬 자격 증명 파일에서 읽어 Anthropic 요청 중 메모리에서 사용합니다. 위젯이 토큰을 별도로 저장하거나 GitHub로 전송하지 않습니다. 위젯의 계정 표시, 한도와 마지막 정상 조회값은 설치된 PC에만 기록됩니다. [데이터 흐름과 보관 파일](PRIVACY.md)을 참고하세요.
