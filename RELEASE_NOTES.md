# v1.0.0

First public Windows 11 x64 release of the Codex + Claude weekly quota tray widget.

- Shows remaining weekly Codex and Claude Code usage next to the system tray.
- Hover shows each weekly reset as `MM-DD(요일) HH:MM 한국시간`.
- Left-click opens the provider's web chat; right-click shows account and refresh details.
- Installer includes a portable Windhawk runtime and registers startup for the current Windows account.

**Requirements:** Python 3 with `pythonw.exe`; npm-installed Codex CLI and Claude Code, each signed in to the desired account. The installer does not include account credentials or prior quota data.

Download `CodexClaudeQuotaTray-Setup.exe` from the release assets. SHA-256: `01A6B45E548FCD6FE589082402703DAF7AF45478BE4F3EECB5534E5A9DB6BF4F`.
